# لینکیار (LinkYar)

افزونه‌ی لینک‌سازی داخلی وردپرس — Persian internal-linking assistant plugin for WordPress.

**وضعیت:** این ریپو فعلاً فقط اسپک (spec) و پرامپت ساخت را دارد. کد افزونه هنوز تولید نشده است.
**Status:** This repo currently contains only the build spec/prompt. Plugin code is not written yet.

- 📋 **پرامپت ساخت (برای OpenCode / Claude Code / Codex):** [`PROMPT.md`](./PROMPT.md)
- 🧩 ماژول‌ها: پیشنهاد لینک داخلی در ویرایشگر · اتولینک هوشمند · گزارش لینک‌های شکسته
- 🌐 زبان UI: فارسی (RTL) · مجوز: GPL-2.0-or-later
